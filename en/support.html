Technical support

When reporting a problem, include the archive format, steps taken, full error message, and your macOS version.

Email supportView GitHub Issues

Common extraction formats

ZIP, RAR, 7z, TAR, tar.gz, tar.bz2, tar.xz, and common split ZIP, RAR, and 7z archives. Encrypted archives require the correct password.

Creation formats

ZIP, 7z, TAR, tar.gz, tar.bz2, tar.xz, JAR, DMG, and ISO. Password and volume options are available where supported by the format.

File permission issues

UnzipX runs in the App Sandbox. Select the files to process and a destination folder. If macOS asks again, select the exact location shown in the prompt. UnzipX does not require Full Disk Access.

Split archives

Start with the first volume, such as .z01, .part01.rar, or .001. Keep every volume in the same folder with an uninterrupted naming sequence.

Password issues

Check capitalization and the active keyboard input source. Frequently used passwords can be saved in the password book and are protected by Apple Keychain.
